# so-permis
Site web vitrine pour SO'Permis

## Contexte du projet

Projet réalisé **en groupe de cinq dans le cadre du BUT Informatique de l’IUT du Havre**, pour la SAÉ S5.01 « Développement avancé ».

Le cahier des charges prévoyait **quatre semaines au total : deux semaines de conception (cahier des charges et maquettes), puis deux semaines de développement**, avec une livraison attendue avant le 21 décembre 2023. Il s’agit du calendrier prévu, et non d’une durée réelle mesurée.
